# University Credentials

Version 1.0 · 2026-08-17

All credentials are **internal competency designations only** — not licensure or professional certification. That disclaimer appears verbatim on every certificate, badge description, and transcript.

## Level credentials (sequential)
| Credential | Granted when | Signatories |
|---|---|---|
| VA1 — Foundational Assistant | VA1 standard met (`03_Competency_Framework/VA_Levels.md`) | Assessor + Manager |
| VA2 — Technical Assistant | VA2 standard met | Assessor + Supervising Veterinarian |
| CVAH VA Core Graduate | All Core graduation requirements met (`03_Competency_Framework/Graduation_Requirements.md`) | Assessor + Supervising Veterinarian + Manager |
| VA3 — Advanced Assistant | VA3 standard met (post-core) | Assessor + Supervising Veterinarian + Manager |

## Specialty credentials (stackable, post-core)
Advanced Perioperative & Anesthesia · Laboratory & IDEXX · Veterinary Dentistry Support · Diagnostic Imaging · Emergency & Critical Care Support · Inpatient Patient Care · Pharmacy & Medication Handling.

Each requires: prerequisites met → specialty knowledge exam pass → specialty case requirements logged → specialty practical assessment pass → credential granted by Assessor + Supervising Veterinarian. Each carries a revalidation interval (`24_Revalidation/Revalidation_Program.md`).

## Badge & certificate system
- Digital badge per credential on learner dashboard and transcript; PDF certificate on request (LMS certificate module).
- Visual spec: `20_LMS/Branding_Guide.md`. Professional, clinical; no cartoon aesthetics.
- A lapsed revalidation renders the badge "expired" on dashboards until revalidated — visible state change, no silent expiry.
