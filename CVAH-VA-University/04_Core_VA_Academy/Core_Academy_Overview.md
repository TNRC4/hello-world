# Core Veterinary Assistant Academy — Curriculum Map

Version 1.0 · 2026-08-17 · Target completion: **6–8 weeks** (competency-based; faster permitted, ~16-week outer window with remediation; calendar never graduates)

## Design
Each week has a **primary outcome** phrased as workload the hospital gains. Lessons follow the 22-part learning-asset template (`Lesson_Template.md`), sized for real training days (10–25 min online + same-day floor practice). Layered learning: core text concise; "Go deeper" expansion blocks optional. Every lesson binds to Technical Skill IDs and question-bank domains. Daily rhythm per `39_Workplace_Integration` pattern (see `27_Deployment/Implementation_Guide.md`): before-shift lesson → designated floor practice → observed attempts → end-of-shift logging → system assigns next.

## Acceleration & remediation
Diagnostic pretest + prior-experience inventory (W0-01) allow **challenge-out**: any module may be skipped by passing its knowledge check ≥90% AND, for skill-bound modules, passing the practical assessment directly (verified mastery — no grandfathering). Learners needing more time repeat *targeted* elements per `23_Remediation/` — never whole weeks by default.
