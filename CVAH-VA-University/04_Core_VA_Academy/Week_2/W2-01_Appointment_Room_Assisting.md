# W2-01 — Appointment Flow & Room Assisting

**Why this matters:** A good room assistant makes every appointment 5 minutes shorter and every DVM's day measurably better. This is Week 2's core workload transfer.

**Objectives:** set up rooms per appointment type; run efficient patient intake (weight, TPR pre-exam per house flow); anticipate during exams; run productive room turnover in the gaps.

**Core instruction:** Room setup by appointment type (wellness: vaccines-anticipated tray, scale path clear; sick visit: sample supplies staged; recheck: prior notes cued for DVM). Intake choreography: weigh (record units the house uses — kg/lb discipline; a units mix-up is a real dosing hazard, always write the unit), TPR per your signed state, presenting-complaint capture in client's words (quoted, not interpreted: chart "coughing all night per owner" — you're a recorder here, not a filter). During exam: position/restrain per DVM ask; anticipate (otoscope handed before asked when the complaint is ears — watch the exam pattern, learn the sequence); capture verbal findings the DVM calls out if asked to scribe. After: room reset per TS-SAN-001, restock sweep.

**Anticipation is learnable:** the lesson includes the "next-three-things" drill — at any exam moment, name silently the three most likely next requests. Trainers quiz this live all week.

**What doesn't look right?** Vaccine drawn up before the DVM confirmed the plan (*never pre-draw before the order is real*); client left alone with an unrestrained fractious dog on a table; weight recorded with no unit.

**Knowledge check:** 1) Owner says "he's been shaking his head." Chart it how? (*As a quote/attributed observation, verbatim-ish, no interpretation.*) 2) When may you pre-draw a vaccine? (*After the DVM's plan/order for THIS visit exists — not on habit.*) 3) The kg/lb rule? (*Always record the unit; know which the PIMS expects; mismatch = flag.*)

**Practical assignment:** run intake on ≥6 appointments; be scored once on the next-three-things drill. **Competency connection:** integrates HND/RES/ASM/DOC states; feeds VA1 grant. **Version:** 1.0 2026-08-17.
