# Technical Skills Library

Every hands-on skill is a first-class object: unique Skill ID, structured metadata, its own instruction, assessment, rubric, repetition requirement, and sign-off process. Skills are never buried inside lecture modules — lessons *point to* skills.

- `Skills_Inventory.csv` — canonical registry (75+ skills). `spec_status`: `full_spec` (complete specification file exists here), `inventoried` (metadata complete; specification authored from `Skill_Template.md` during rollout month 1–2 — tracked in manifest), `equipment_dependent` (blocked on Equipment Registry discovery).
- `Skill_Template.md` — the mandatory 33-field structure for every specification.
- `TS-*.md` — full specifications. Deepest: venipuncture set and IV catheterization.

ID scheme: `TS-<domain>-<site/variant>-<seq>`; domains: HND handling, RES restraint, ASM assessment, SAN sanitation, DOC documentation, COM communication, VEN venipuncture, IVC IV catheter, INJ injection, MED medication, SAM samples, LAB lab bench, FLU fluids, SUR surgery, IMG imaging, EMR emergency readiness, INP inpatient, PRO procedures, ANE anesthesia academy, LID lab/IDEXX academy, DEN dentistry, ECC emergency academy, PHA pharmacy.
