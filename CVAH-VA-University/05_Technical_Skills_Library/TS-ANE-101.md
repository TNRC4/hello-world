# TS-ANE-101 — Anesthesia Machine Check & Leak Test

**School/Level:** Anesthesia Academy / VA3-track · **Prereq:** Academy enrollment; ANE-M2 equipment module · **Scope/Supervision:** P/S1 — performed as pre-op support, verified by anesthetist; the anesthetist retains machine responsibility · **Revalidation:** 12 months

**Daily/pre-case check (assistant-performable, anesthetist-verified):** 1) Oxygen source: pipeline/cylinder pressure adequate (cylinder open, wrench present, reserve per policy); 2) flowmeter: smooth bobbin travel, no stick; 3) vaporizer: agent level in window, filler cap tight, interlock seated, dial at zero; 4) CO2 absorbent: color check + granule feel per product, change log current (exhausted absorbent = rebreathing); 5) circuit assembly correct for patient size per anesthetist's selection (rebreathing vs non-rebreathing — assistant assembles, anesthetist confirms choice); reservoir bag size per chart; 6) scavenging connected (active system on / passive canister weighed & in-date); 7) **pressure/leak test (rebreathing):** close APL (pop-off), occlude patient end, fill circuit via O2 flush/flow to 30 cmH2O on manometer — needle must hold (leak rate within house limit, e.g. holds ≥10 s or ≤ specified mL/min flow to maintain); **OPEN THE APL BEFORE RELEASING THE OCCLUSION** and confirm pop-off open at test end — an APL left closed is the classic lethal error; 8) non-rebreathing circuit leak check per circuit type; 9) suction on and reachable; airway kit staged (tubes ×3 sizes, stylet, lube, tie, cuff syringe, laryngoscope light checked).

**Critical fails:** APL left closed at test end (automatic fail + drill reset); leak test skipped/pencil-whipped; vaporizer interlock/cap issue missed. **Repetitions:** ≥10 verified checks; ≥1 staged-fault check (trainer plants a leak/closed APL/exhausted absorbent — learner must catch). **Practical:** PA-ANES-MACH-001. **Knowledge:** QB-ANES equipment items. **Video:** VID-ANE-101 (manometer close-up, APL discipline). **Sources:** anesthesia machine manufacturer manual (registry); veterinary anesthesia texts (Lumb & Jones-lineage, paraphrase); ACVAA monitoring guidelines context. **Rev:** 1.0 2026-08-17, PENDING.
