# TS-ASM-001 — TPR Acquisition & Documentation

**School/Level:** Core/VA1 · **Prereq:** TS-HND-001 · **Scope/Supervision:** P/S2 · **Revalidation:** none

**Equipment:** digital rectal thermometer + probe covers + lube; watch/timer with seconds; stethoscope. **Patient considerations:** rectal temp contraindications (rectal disease/surgery, severe thrombocytopenia per DVM, extremely fractious — use axillary flag noted as such); count RR **before** touching the patient (handling elevates it); crying/purring confounds — note it.

**Anatomy/physiology:** heart auscultation landmark: left thorax at/behind the elbow (apex beat); femoral pulse: medial thigh, groove between muscles; each heartbeat should produce one femoral pulse — a beat without a pulse (pulse deficit) is reportable. One respiration = one full in+out cycle.

**Procedure:** 1) Observe RR from a distance for 15 s ×4 (or 30 s ×2 if steady); note character (effort, abdominal push, noise, stertor/stridor). 2) Auscultate heart 15–60 s; simultaneously palpate femoral pulse; count HR, note rhythm regularity and pulse synchrony/quality (strong/weak/bounding). 3) Temperature: cover + lube, gentle insertion 1–2 cm, stay with the patient, read, dispose cover. 4) While hands-on: gums (color, moisture), CRT (<2 s standard), quick hydration observation (skin tent over shoulders, tacky gums). 5) Record immediately with time and your initials; compare against CRC-001 bands; report any out-of-band value NOW, not at end of shift.

**Common mistakes:** counting RR after wrestling the patient; half-cycles counted (doubling RR); thermometer left unattended; recording from memory later; failure to note "purring — HR unreliable"; calling panting a respiratory rate. **Troubleshooting:** can't hear heart (obese/deep-chested) → move stethoscope cranioventrally, use femoral pulse count as cross-check; squirming → second handler rather than a bad number — a wrong value is worse than a delayed one.

**Stop criteria:** distress from handling; rectal resistance/pain. **Escalation (immediate report):** any CRC-001 out-of-band value; pulse deficit; laboured breathing at rest; pale/white/blue/brick-red gums; CRT >2 s.

**Documentation:** T, P (with rhythm/quality notes), R (with character), MM/CRT, time, initials. **Video:** VID-ASM-001. **Simulation:** heart-sound audio set (LMS INT-09) + rate-counting drills. **Knowledge:** QB-CORE-ASM. **Practical:** PA-ASM-TPR-001. **Critical fails:** fabricated/estimated values; failure to report a grossly abnormal value; wrong patient. **Repetitions:** ≥10 coached TPRs (≥3 cats) with values matching the trainer's within tolerance (T ±0.2°F, HR ±8 bpm, RR ±4 rpm) on ≥8. **Sign-off:** Assessor. **Sources:** McCurnin's; CRC-001 (DVM-approved ranges). **Rev:** 1.0 2026-08-17, PENDING.
