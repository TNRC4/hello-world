# TS-DOC-001 — Basic Medical-Record Documentation

**School/Level:** Core/VA1 · **Prereq:** none · **Scope/Supervision:** P/S2 · **Revalidation:** none

**System:** CVAH PIMS `[CVAH-SPECIFIC INPUT REQUIRED: system name; lesson W1-06 carries the click-path appendix]`.

**Principles:** the record is a legal document; if it isn't written, it didn't happen; write observations, not diagnoses ("gums pale pink, CRT 3 s" — never "patient is anemic"); every entry carries time and initials; never delete — correct by addendum per PIMS convention; record at the time of the event, not end of shift; abbreviations only from the hospital-approved list (appendix to W1-06).

**Procedure (treatment entry):** patient ID verified on the open chart (name + client + species match the patient in front of you — the classic error is charting on the sibling pet); enter task, values, patient response, complications ("none" is a finding), time, initials; abnormals additionally reported verbally (TS-COM-001) and flagged per PIMS convention.

**Common mistakes:** batch-charting at shift end; vague entries ("did meds"); charting intentions as facts (charting a med before giving it — never); editorializing about clients or patients; copying forward yesterday's note. **Critical fails:** wrong-patient entry unnoticed; pre-charting an unadministered treatment; altering a record other than by addendum. **Assessment:** documentation audit (10 consecutive entries — graduation gate 7) + PA embedded items. **Knowledge:** QB-CORE-SAF/DOC items. **Sources:** AVMA records guidance; AZ record-keeping rules (verify current A.A.C. requirements at deployment). **Rev:** 1.0 2026-08-17, PENDING.
