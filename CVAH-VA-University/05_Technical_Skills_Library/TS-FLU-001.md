# TS-FLU-001 — Fluid Line Setup, Priming & Bag Changes

**School/Level:** Core/VA2 · **Prereq:** W4-04 · **Scope/Supervision:** P/S2; fluid TYPE and RATE always from DVM order — assistants set up and monitor, never choose · **Revalidation:** none

**Equipment:** ordered fluid bag; administration set (macro 10 or 15 gtt/mL, micro/pediatric 60 gtt/mL — house stock `[CVAH-SPECIFIC INPUT REQUIRED]`); extension set; labels.

**Setup/priming:** 1) Verify order (fluid type, volume, rate, additives) and bag integrity (squeeze test for leaks, clarity, expiration — cloudy/particulate = discard); 2) additives are CVT/DVM territory — an additive-labeled bag is verified by them before you hang it; 3) close roller clamp; spike port aseptically (straight push, no touching spike); 4) hang, squeeze drip chamber to 1/3–1/2 full; 5) open clamp, prime line slowly to the end, chase bubbles by tapping — champagne bubbles matter more in small patients, be thorough regardless; 6) cap end sterile until connection; 7) label line/bag with date/time started, set type, initials; 8) connect to catheter T-port aseptically, secure with enough slack loop that patient movement pulls tape, not catheter.

**Pump vs gravity:** rate setting on pump is entered by CVT/DVM or verified by them per policy; gravity drip-rate math taught for understanding and pump-failure fallback: drops/min = (mL/h ÷ 60) × set gtt/mL.

**Bag change:** new bag verified against order; close clamp; swap spike aseptically (no touching); restart; document remaining/discarded volumes (I/O math on treatment sheet).

**Line monitoring (hourly minimum):** pump display vs bag reality (a pump can happily count while the line delivers sub-q); trace the entire line patient→bag every check ("trace the line" is the taught reflex); catheter-site check (swelling, wet fur, heat, pain = infiltration signs → stop flow, report); tangle/kink/chew audit; patient mobility maintained (no limb-strangling loops).

**Common mistakes:** priming with clamp half-open (air segments); drip chamber overfilled (can't count drops); connecting an unprimed line ("just a little air" is not a plan); slack directly on the catheter hub; assuming the pump is truth. **Critical fails:** hanging unverified additive fluids; connecting visibly air-filled line; ignoring an infiltration sign found on check. **Repetitions:** ≥5 supervised setups incl. 1 bag change + 1 pediatric set. **Practical:** graduation station 7. **Knowledge:** QB-CORE-FLU. **Video:** VID-FLU-001. **Sources:** AAHA fluid therapy guidelines (educational framing); set manufacturer IFU. **Rev:** 1.0 2026-08-17, PENDING.
