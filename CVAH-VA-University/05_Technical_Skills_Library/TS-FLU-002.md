# TS-FLU-002 — Infusion & Syringe Pump Operation

**School/Level:** Core/VA2 · **Prereq:** TS-FLU-001 · **Scope/Supervision:** P/S2; rate entry per policy verified by CVT/DVM · **Revalidation:** 12 months (equipment competency)

**Equipment:** house pump models `[CVAH-SPECIFIC INPUT REQUIRED: models → equipment registry rows EQ-PUMP-*; this spec carries model-agnostic competencies, registry carries button-level job aids]`.

**Model-agnostic competencies:** correct set loaded in correct orientation (pumps meter by squeezing tubing — wrong set = wrong delivery); door/clamp engagement; entering/verifying rate and VTBI (volume to be infused) against written order with CVT/DVM check; distinguishing mL/h from mL total (classic error class); starting/pausing without free-flow (roller clamp closed before door opens — free-flow bolus prevention is THE safety behavior); alarm response tree; battery vs mains awareness during transport; syringe pump: correct syringe brand/size selection on menu (pump calibrates force by syringe model), plunger seating, anti-siphon awareness.

**Alarm response tree (taught + drilled):** OCCLUSION → trace line: kink? clamp? catheter positional? site infiltrated? — resolve mechanical causes; if catheter suspected, flush assessment per TS-IVC-002; never silence-and-walk. AIR-IN-LINE → clamp, disconnect at port per protocol, re-prime segment or replace line; never open the door and "flick it through" toward the patient. NEARLY-EMPTY/VTBI → prepare next bag with verification lead time. UNRESOLVED IN 2 MIN or repeating → escalate to CVT; a nuisance-alarming pump goes to the "out of service" shelf with a tag, never back into rotation quietly.

**Critical fails:** free-flow event caused by clamp discipline failure; silencing an alarm without tracing the line; syringe-menu mismatch left uncorrected. **Repetitions:** ≥5 supervised pump setups + alarm drill (trainer stages occlusion + air alarms). **Practical:** station 7 element. **Knowledge:** QB-CORE-FLU. **Video:** per-model job-aid videos (registry-driven). **Sources:** manufacturer manuals (registry-linked). **Rev:** 1.0 2026-08-17, PENDING.
