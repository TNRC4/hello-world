# TS-LAB-002 — PCV/TS Measurement

**School/Level:** Core/VA2 · **Prereq:** TS-SAM-001 · **Scope/Supervision:** P/S2 · **Revalidation:** none

**Equipment:** microhematocrit tubes (heparinized for direct/ EDTA blood in plain), clay sealant, microhematocrit centrifuge, reader card, refractometer.

**Procedure:** 1) Fill two tubes ~3/4 from well-mixed EDTA sample (two = built-in error check); 2) Seal one end with clay (two firm presses, no blood on outside); 3) Load centrifuge clay-OUT against gasket, balanced opposite each other, lid ON; 4) Spin per house setting (typically ~5 min at microhematocrit speed — post setting on machine card); 5) Read PCV on card: align clay-cell interface at 0, plasma meniscus at 100, read packed-cell top; average the two tubes (>2% disagreement = redo); 6) Note plasma color: clear/straw normal — record hemolysis (pink), lipemia (milky), icterus (yellow) — these are FINDINGS, report them; note buffy coat prominence; 7) Snap tube above cells, drop plasma onto refractometer, read TS on serum-protein scale; 8) Record PCV %, TS g/dL, plasma character, time, initials; report against CRC-001 bands.

**Common mistakes:** clay-in loading (blood sprays out); unbalanced rotor (walks the counter, breaks tubes); reading the buffy coat into the PCV; refractometer not zeroed with distilled water (daily QC — part of this skill); lipemic plasma TS read as gospel (lipemia falsely raises it — flag). **Critical fails:** reporting values from a single grossly hemolyzed tube without flagging; centrifuge run without lid. **Repetitions:** ≥5 supervised with paired-tube agreement. **Knowledge:** QB-CORE-LAB. **Video:** VID-LAB-002. **Sources:** clinical pathology references; refractometer manual. **Rev:** 1.0 2026-08-17, PENDING.
