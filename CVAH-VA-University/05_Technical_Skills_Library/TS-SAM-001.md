# TS-SAM-001 — Blood Tube Selection, Filling, Mixing & Labeling

**School/Level:** Core/VA2 · **Prereq:** TS-VEN theory · **Scope/Supervision:** P/S2 · **Revalidation:** none

**Tube map (house-stocked; confirm colors against supplier):** *Lavender/EDTA* — CBC/hematology; fill to line (underfill shrinks cells/skews values), invert 8–10× gently, IMMEDIATELY after draw. *Red plain (no additive)* — serum chemistry/serology; let clot upright 20–30 min before spin. *Tiger-top/SST (gel)* — serum with separator; not for all send-out tests (some drug levels bind gel — check lab directory). *Green/heparin* — plasma chemistries where used (Catalyst workflows per Lab Academy). *Blue/citrate* — coagulation; **exact fill line is mandatory** (9:1 blood:citrate ratio — a short blue tube is garbage data), invert 3–4×. *Gray/fluoride* — glucose stability where used.

**Fill order (syringe transfer, house standard):** citrate → EDTA → heparin → serum tubes when volume is tight and coags matter; rationale: clotting starts at draw — anticoagulant tubes get blood first; `[CVAH-SPECIFIC INPUT REQUIRED: confirm house order with reference lab's directory; some order conventions differ for vacuum draws]`.

**Technique:** remove needle before transferring to tubes (pushing through stopper via needle hemolyzes and is a sharps risk) OR per house transfer-device policy; run blood down the tube wall gently; never push the plunger hard; mix by inversion, never shaking; label AT PATIENT-SIDE: patient, client, date/time, initials — an unlabeled tube in a rack is a discard-level error.

**Preanalytic error catalog (the recognition core):** hemolysis (pink/red serum) ← aspiration too hard, small needle + big vacuum, needle-through-stopper transfer, shaking, alcohol not dry; clotted EDTA ← slow transfer, poor mixing → CBC invalid, redraw; lipemia ← non-fasted (note it, not your fault, but flag); underfilled citrate ← invalid coag. Learner must be able to name the cause from the artifact.

**Storage/reference-lab prep:** per test directory — serum separated within 30–60 min for many chemistries; refrigerate vs room-temp per test; cytology slides NEVER refrigerated with formalin nearby (fumes fix cells). **Critical fails:** unlabeled sample leaving the room; shaking a tube; knowingly submitting a compromised sample without flagging. **Repetitions:** every draw; assessed at station 5. **Knowledge:** QB-CORE-LAB. **Sources:** reference-lab directory `[CVAH-SPECIFIC INPUT REQUIRED: IDEXX directory link]`; McCurnin's. **Rev:** 1.0 2026-08-17, PENDING.
