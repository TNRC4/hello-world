# ANE-L3 — The Anesthesia Machine: Gas Path Mastery & Fault Finding
Tier T2 course · builds on TS-ANE-101 · ~30 min + machine lab

## 1. The gas path, narrated (the walk-through you must be able to give)
Stand at the machine and trace with your hand, saying it aloud — this narration IS the assessment: "Oxygen arrives from the pipeline/cylinder at high pressure → the REGULATOR steps it down to working pressure → the FLOWMETER meters it (bobbin reads at its center/top per model) → through the VAPORIZER, which adds a dialed percentage of agent → out the COMMON GAS OUTLET → into the circuit's INSPIRATORY limb → one-way inspiratory VALVE (watch it flip) → the patient breathes it → EXPIRATORY limb → one-way expiratory valve → past the APL (pop-off), which vents excess to SCAVENGING → through the CO2 ABSORBENT canister, which strips CO2 → around again, topped up by fresh gas. The RESERVOIR BAG hangs off the loop as the compliance buffer — and my window into breathing." Non-rebreathing circuits bypass absorber/valves: high fresh-gas flow does the CO2 clearance — which is why flow settings are life-critical there.

## 2. What each part's failure looks like (the fault catalog)
| Fault | What you'd notice | First check | Why it matters |
|---|---|---|---|
| Circuit disconnection | Capnograph flat, bag limp/still, agent smell | Y-piece and every joint, patient-end first | Minutes to hypoxia; commonest "sudden flat EtCO2" |
| APL left closed | Bag ballooning tight, manometer climbing, patient can't exhale | APL position — open NOW is anesthetist's move; your job is the loud call | Barotrauma in under a minute |
| Exhausted absorbent | Inspired CO2 >0, baseline lifts; granules hard/spent per change log | Canister log + capnograph baseline | Patient rebreathes own CO2 |
| Stuck one-way valve | Baseline lift with fresh absorbent; valve disc not fluttering | Watch both valve domes through a breath cycle | Same rebreathing, sneakier cause |
| Leak (circuit/machine) | Bag deflating between breaths, agent smell, pressure won't hold | The pre-case leak test finds it FIRST; intra-op: joints, bag neck, tube cuff | Light patient + OR gas exposure |
| Empty/failing O2 supply | Line pressure alarm, flowmeter bobbin falling | Cylinder gauge/pipeline; know the backup cylinder location + wrench | Everything downstream dies without it |
| Vaporizer empty/overfilled/tilted | Agent % vs dial mismatch (light patient at "adequate" setting; or overdose signs) | Sight-glass level; report — never refill mid-case yourself unless trained+directed | Depth chaos with a "normal" dial |
| Wrong circuit for size | Big-bag small-patient (can't see breaths, dead space) or reverse | Chart-vs-setup check at machine check time | Hidden hypoventilation |
| Scavenging blocked/off | Agent smell, waste-gas alarm where fitted, bag behavior odd | Scavenge line connection and interface | Staff exposure + circuit pressure effects |
| Sampling line water-trap full / kinked | Capnograph dampened/flat with a BREATHING patient | The line and trap, before declaring patient trouble | The commonest "false emergency" |

## 3. The fault-finding drill (lab; repeated at assessment)
Trainer rigs ONE fault from the catalog on a checked machine (patient = test lung/bag). You run the standard machine check narrating aloud; the assessment is (a) did the check CATCH it, (b) did you name the consequence ("this absorbent is spent — patient would rebreathe"), (c) did you respond in-role (fix what's yours: reconnect a found disconnection at setup; call what isn't: APL/vaporizer states). Ten faults, randomized across sessions; mastery = 10/10 catches across any two sessions. **The two career-rules this drill installs:** the leak test is never pencil-whipped, and the APL is confirmed OPEN at every test's end, out loud.

## 4. "What doesn't fit?" machine edition (sample reasoning items — full set in SIM library)
Bag moving but capnograph flat → sampling line before panic, patient-check simultaneously. · Manometer creeping up between breaths → APL/scavenge question NOW. · Fresh absorbent, baseline still lifted → valves, not granules. · Bobbin at 1 L but bag slowly emptying → leak hunt. Each item scores BOTH the diagnosis-path and the urgency call.
