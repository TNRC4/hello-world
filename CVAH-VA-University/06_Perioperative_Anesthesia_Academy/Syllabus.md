## Modules
**ANE-M1 — Cardiopulmonary Physiology (2 wks).** Cardiac cycle and electrical conduction (P-QRS-T mapped to mechanical events); cardiac output = HR × SV; preload/afterload/contractility with hospital-floor translations (what bleeding does to preload; what vasodilating inhalants do to afterload); vascular resistance and perfusion vs pressure (why MAP is a proxy, not the goal); respiratory mechanics: ventilation vs oxygenation as separable failures; minute ventilation; dead space (anatomic + equipment); CO2 transport and what EtCO2 actually samples; O2 transport: why SpO2 lags on oxygen; anesthetic-agent physiologic signatures. Assessment: QB-ANES M1 items + labeled-diagram interactives (INT-A1 cardiac cycle; INT-A2 gas exchange).
**ANE-M2 — The Machine (1–2 wks).** Full gas path O2 source→regulator→flowmeter→vaporizer→circuit→patient→absorber→scavenger; rebreathing vs non-rebreathing selection logic; reservoir bags; APL discipline; leak tests; ET tubes/cuffs/laryngoscopes/suction; monitors as instruments (what each transducer physically measures). Skills: TS-ANE-101, TS-ANE-102, TS-ANE-105. Assessment: PA-ANES-MACH-001 incl. staged-fault checks.
**ANE-M3 — Monitoring Deep Dive (2–3 wks).** Lesson ANE-L1 (capnography — full lesson below); ECG lead placement + normal vs the report-now rhythms at recognition level (bradyarrhythmia trends, VPC runs, chaos-vs-artifact discipline); pulse oximetry physics + failure modes; oscillometric vs Doppler BP + cuff science; temperature as an anesthetic variable; anesthetic depth by eyes-and-hands (palpebral, jaw tone, eye position) supporting the anesthetist's assessment. Skills: TS-ANE-103, TS-ANE-104. Assessment: waveform-interpretation set (30 tracings: capnograms ×12, pleth ×8, ECG ×10) ≥85%.
**ANE-M4 — Trend-Based Clinical Reasoning (2 wks).** SIM-ANES-001..006 worked cohort-style; the five-question discipline (what changed first / real or artifact / what confirms / what do I physically check / how urgent); building the verbal report for each. Assessment: sim set ≥85% + live staged-drill case.
**ANE-M5 — Pharmacology for Monitors (1–2 wks).** Educational signatures of drug classes (sedatives/alpha-2s/opioids/benzos/anticholinergics/induction agents/dissociatives/inhalants/locals/NSAIDs/adjuncts/emergency+reversal agents): expected HR/BP/resp/temp effects so monitoring anticipates rather than reacts; current Plumb's + ACVAA-aligned texts as sources, paraphrase-only. Explicit non-goals: no dosing, no selection, no protocol talk beyond recognition.
**ANE-M6 — Surgical Assisting (1–2 wks).** Gowning/gloving assistance; sterile zones; instrument passing patterns; suture recognition; pack/sterilization QA (extends Core W5-04); counts; specimen handling chain (label-in-formalin rules, margins-untouched doctrine); room turnover choreography. Skill: TS-ANE-107.
**ANE-M7 — Recovery & Crisis Recognition (2 wks).** Recovery as anesthesia's highest-vigilance phase (extends W6-02 to specialty depth: extubation-readiness observation, feline recovery patterns, brachycephalic protocols, dysphoria-vs-pain description skills, regurgitation/aspiration response); crisis catalogue with role-specific responses: hypotension, hyper/hypocapnia, hypoxemia, bradycardia/tachycardia, apnea, airway obstruction, circuit disconnection, rebreathing, oxygen failure, hypothermia, depth extremes, arrest (RECOVER interface). Skill: TS-ANE-106. Assessment: crisis-recognition scenario exam + PA-ANES-MON-001.

## Case requirements
≥15 monitored cases logged (role: monitoring support/recorder) spanning ≥3 procedure types incl. ≥1 dental ≥60 min and ≥2 feline; ≥10 machine checks; ≥5 recoveries incl. 1 brachycephalic (or simulated if case-mix lacks); each case countersigned by the anesthetist.

## Credential gates
QB-ANES exam ≥85% (SC items 100%) · waveform set ≥85% · SIM-ANES set complete · case log complete · PA-ANES-MACH-001 + PA-ANES-MON-001 passed · Medical Reviewer countersign.
