# Assessment System Blueprint

Version 1.0 · 2026-08-17

## Instrument map
| Instrument | When | Purpose | Standard |
|---|---|---|---|
| Diagnostic pretest | Week 0 | Placement, challenge-out routing | No pass bar; scores route plan |
| Lesson knowledge checks | Every lesson | Immediate retrieval, gate to floor practice | ≥80% (safety modules 100%), unlimited retakes with fresh randomized items |
| Module quizzes | End of each week | Consolidation, spaced retrieval (each includes 20% prior-week items) | ≥80% |
| Med-math screen | Week 2, re-testable | VA2 math gate | ≥90% (Pharmacy Academy: 95%) |
| Recognition battery | Week 7 | Question 3 of competence, formally | ≥85% + all critical-recognition items |
| Core final exam | Week 6–8 (whenever ready) | Gate 1 | ≥80% + embedded safety items 100% |
| Practical assessments (PA-*) | Per skill readiness | Gate 3 | Rubric-defined, zero critical fails |
| Core Graduation Practical | Graduation | Gate 8 | ≥11/13 stations incl. all 5 safety-critical |
| Specialty exams & practicals | Per academy | Credential gates | Per academy syllabus |

## Item standards
Every item carries: ID, school, module, skill/objective ID, difficulty (1–3), cognitive level (Recall/Apply/Analyze), safety-critical flag, stem, options, key, explanation, distractor rationale where non-obvious, source. Format spec: `14_Question_Banks/QB_Format_Specification.md`. Banks are sized for randomization (multiple forms without repeats); bank growth targets in manifest (Core: 190 at launch → 400 by month 6; each item written by staff enters review per medical-review workflow).

## Exam assembly
Forms are assembled by blueprint (domain weights below), drawing randomly within domain and difficulty strata; safety-critical items always included. Core final blueprint: `Core_Final_Exam_Blueprint.md`.

## Integrity & fairness
Practical assessors use only observable-behavior rubrics; knowledge exams proctored per policy; accommodations per HR policy; every failed attempt generates a targeted remediation assignment automatically (never a bare "retake").
