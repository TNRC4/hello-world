# Core Graduation Practical — 13 Stations

**Format:** circuit run in one morning (or two blocks); each station 8–12 min; standardized setups; two assessors split the circuit; scripted probes fixed per exam cycle for fairness. **Pass:** ≥11/13 stations passed INCLUDING all five safety-critical (★) stations; zero critical fails anywhere. A CF fails that station and triggers targeted remediation before re-attempt of that station only.

**Station 11 build sheet:** kennel A — treatment sheet shows NPO but food bowl present (must catch/resolve); kennel B — "patient" (model/volunteer dog) with vetwrap applied wet and snug (must flag); kennel C — trend chart HR rising across three checks below threshold (must report trend). Detection AND correct urgency both scored.

**Logistics:** patients: staff-owned volunteers/models per ethics note (no extra procedures on clinical patients for exam purposes — live elements ride real ordered care where timing allows, else models); paperwork pack printed per candidate; results entered into passport same day; readiness review scheduled within one week of pass.
