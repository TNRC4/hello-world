# Specialty Practical Assessments (compact rubrics)

Standards per `Rubric_Standards.md`. Pass ≥80%, no ★ zeros, zero CFs, assessor = CVT/DVM with the relevant competency.

## PA-ANES-MACH-001 (machine check & leak test)
Full check sequence order (O2 → flow → vaporizer → absorbent → circuit build → scavenge → leak test → airway kit) · ★leak test executed with manometer discipline · ★APL reopened and verbalized at test end · staged fault caught (planted: closed APL / exhausted absorbent / circuit leak — drawn by lot) · documentation on machine log. CFs: APL left closed · staged fault missed AND signed off.

## PA-ANES-MON-001 (monitoring support, live case + drill)
Live case: 5-min cycle discipline sustained (hands-eyes before numbers) · record complete, trends drawn, events stamped · ★report thresholds honored per CRC-003 (staged prompt if quiet case) · artifact check sequence performed with simultaneous report · ★no silent troubleshooting; no dial-touching (probe scripted: anesthetist absent, "just turn it down a touch" note left — must refuse/clarify live with DVM). Drill: one SIM-ANES case run live with verbal five-question reasoning. CFs: fabricated record cell · vaporizer/APL touched without direct in-the-moment instruction · deterioration observed and unreported.

## PA-ECC-001 (emergency support)
2-min compression cycle: rate in 100–120 (metronome-verified), recoil, swap <5 s gap (2/1/0 each, ★rate) · staging drill under time standard · role scenario with ★closed-loop repeats (3 planted) · recorder exercise vs script ≥90% capture · cart audit performed honestly (planted deficiency must block signature ★). CFs: role freelancing (drug handling) · cart signed with deficiency.

## PA-INP-001 (ward practical)
Planted-abnormality round (3 plants; ≥2 caught with correct urgency, ★the report-now plant) · device circuit: line trace, urinary system, feeding-tube site, bandage checks narrated · I/O math exercise correct · pain-score calibration case within 1 point · ★handoff given to rubric (trend/due/watch/read-back). CFs: report-now plant missed · fabricated check.

## PA-LID-001 (lab QC practical)
Daily QC cycle run + logged correctly · ★staged QC failure: response tree followed, patient sample correctly held/rerouted · analyzer maintenance task performed per job aid · smear-quality gate applied (bad smear remade unprompted) · error-code lookup exercise. CFs: patient result released over failed QC.

## PA-DEN-001 (dental support practical)
Full-mouth series on model: diagnostic quality, ≤20% retakes, ★series counted complete before "waking" · station setup/breakdown to checklist · ★staged pooling/hypothermia events reported · charting scribe exercise ≥90% accuracy. CFs: staged airway event missed · gag policy violated.

## PA-IMG-101 (imaging portfolio defense)
Portfolio of 12 studies reviewed with assessor: candidate self-identifies any faults per image (★self-audit accuracy) · live study: full PA-IMG-001 anchors at specialty polish · fault-gallery spot test ≥90%. CFs: as PA-IMG-001.

## PA-PHA-001 (dispensing line practical)
Order set of 5 processed: ★ambiguous order stopped · ★LASA trap caught · count discrepancy caught and reported · labels/logs audit-clean · verification choreography with verifier correct · controlled-substance mock draw witnessed/logged/balanced. CFs: trap dispensed · discrepancy "fixed" without report.
