# Practical Assessment Standards

All PA rubrics use observable behavioral anchors only. Scoring per step: **2** = performed correctly without prompt · **1** = performed with minor prompt/self-corrected hesitation · **0** = not performed / performed incorrectly / required full prompt. **CF** = critical fail (attempt ends immediately, automatic fail regardless of score; targeted remediation assigned before re-attempt).

Pass standard per rubric: stated minimum % of available points AND no step scored 0 in sections marked ★ AND zero CFs. Assessor requirements per `01_University_Governance/Governance_Roles.md`. Every assessment records: date, patient/model, context, per-step scores, narrative strengths/gaps, remediation if assigned, assessor signature, learner signature (acknowledgment, not agreement requirement).

Banned scoring language: "seems comfortable," "pretty good," "has the idea." If it isn't a behavior you observed, it isn't on the form.
