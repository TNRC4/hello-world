# SIM-ANES-001..006 — Anesthesia Trend Cases (tabletop/LMS, Anesthesia Academy)

Format per case: 5-min-interval vitals table unfolds row by row; at each reveal the learner answers: What changed first? Real or artifact-possible? What physically checks it? Report now/soon? What exactly would you say? Model answers keyed; ≥85% across the set required for TS-ANE-103 knowledge gate. (Values are teaching constructs; live alert thresholds come from CRC-003.)

**SIM-ANES-001 "The Slow Slide" (hypotension development):** Spay, 2y Lab. T0: HR 92 SpO2 98 EtCO2 42 MAP 72 T 100.8 · T5: 88/98/44/65/100.4 · T10: 84/97/46/58/100.1 · T15: 82/97/47/52/99.7. Key: MAP trend crossed alert band by T10–15 while everything else stays "fine-ish"; first-change = MAP at T5–10; artifact check = cuff size/site, but a clean serial trend across readings argues real; report by T10 with trend language, not at T15 with a crisis.

**SIM-ANES-002 "The Flat Line That Wasn't" (disconnection vs arrest):** Dental, 9y poodle. T20 sudden EtCO2 0 flat, SpO2 97 (lagging), HR unchanged. Key: hands-on first — chest movement? bag moving? circuit connected? Sampling line kinked? Most common answer: popped Y-piece at repositioning; teach why SpO2 stays falsely reassuring on oxygen; report simultaneously with the physical check, not after.

**SIM-ANES-003 "Rebreathing" :** Long dental. Baseline EtCO2 38 with inspired CO2 0 · T60: 44, inspired 3 · T75: 49, inspired 6. Key: rising inspired baseline = rebreathing; absorbent exhaustion/valve fault; check canister log/color, one-way valves; report — anesthetist decides absorber change/flow changes.

**SIM-ANES-004 "The Cold Cat":** 3.2 kg cat, T trend 100.2→98.9→97.6→96.4 over 45 min, HR drifting 160→120, depth "seems deeper" at same vaporizer setting. Key: hypothermia deepens anesthesia and drops HR; first change = temperature at T15; your levers = warming devices per direction + report trend early; classic error = reading falling HR as "nice and stable."

**SIM-ANES-005 "Shark Fins":** Bulldog, mid-procedure capnogram upslope slurs progressively, EtCO2 creeping, mild effort visible. Key: expiratory obstruction pattern — kinked tube/secretions/circuit; physical checks: tube position/kink, tube lumen (suction ask), circuit; brachycephalic context raises stakes; report with the waveform described in words.

**SIM-ANES-006 "The Pretty Number" (artifact discipline):** SpO2 91→88 with progressively ragged pleth after limb repositioning; HR/EtCO2/BP/MM all rock-solid. Key: probe repositioning + report BOTH facts ("SpO2 88 but pleth is ragged since the move; everything else agrees patient looks good; repositioning probe"); teach: artifact is a hypothesis you TEST, never a conclusion that lets you silence an alarm.
