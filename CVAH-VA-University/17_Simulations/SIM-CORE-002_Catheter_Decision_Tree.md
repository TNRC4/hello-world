# SIM-CORE-002 — IV Catheter Branching Scenario (digital, Week 4)

**Format:** branching scenario (H5P Branching Scenario or LMS lesson tool). 8 nodes; wrong branches play consequences then loop to teaching point.
**Script spine:** Node 1: flash on entry, thread resists at 2 mm. Options: force it (→ consequence: blown vein animation, teach) / advance-unit-flatten-retry (✓) / pull catheter back over stylet (→ shear-risk teaching stop, hard fail flag) / remove as unit + new site (acceptable if retry logic explained). Node 2: second site, flash, threads, flush raises soft bleb → options: continue slowly (✗ consequence) / stop-report-restick (✓) / tape it anyway (✗). Node 3: securing choices (tension test). Node 4: 4 h later — pump occlusion alarm branch (trace → kink found at carpus → re-tape with neutral carpus ✓). Node 5: next morning — warm red tracking cord option set (report/expect removal ✓). Scoring: ≥85% first-pass branch accuracy; hard-fail branches (shear, force-flush) require module review before retry.
