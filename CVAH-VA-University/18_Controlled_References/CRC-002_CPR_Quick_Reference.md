# CRC-002 — CPR Quick Reference (RECOVER 2024-aligned) ⚠ DRAFT — PENDING DVM APPROVAL — NOT FOR CLINICAL USE

Version 0.9-draft · Drafted 2026-08-17 · Reviewing veterinarian: ________ · Next review: on RECOVER guideline update or 24 months · Sources: RECOVER 2024 Guidelines (recoverinitiative.org; JVECC 2024 BLS/ALS papers).

**Recognition→start:** unresponsive + not breathing normally → announce arrest, start compressions immediately.
**Compressions:** 100–120/min · lateral recumbency default · depth 1/3–1/2 chest width (lateral) · full recoil · 2-min uninterrupted cycles · swap compressor each cycle · conformation techniques: round-chest = highest point; keel-chest = over heart; barrel/bulldog = consider dorsal per lead; cats/small = one-hand circumferential or two-finger.
**Ventilation:** not intubated = 30:2 with tight mask · intubated (CVT/DVM secures airway) = continuous compressions + ~10 breaths/min, avoid hyperventilation.
**Team:** closed-loop repeats · recorder logs all events timestamped · EtCO2 trend = compression-quality feedback; sharp rise = possible ROSC → announce.
**Drugs/defibrillation:** DVM/CVT domain — dosing chart posted on cart (DVM-approved separately).
