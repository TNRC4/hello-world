# CRC-003 — Anesthesia Monitoring Alert Thresholds ⚠ DRAFT — PENDING DVM APPROVAL — NOT FOR CLINICAL USE

Version 0.9-draft · Drafted 2026-08-17 · Reviewing veterinarian: ________ · Next review: 12 months post-approval · Sources: ACVAA small-animal monitoring guidelines; veterinary anesthesia texts; reviewing DVM's case-default preferences.

Default REPORT-NOW bands for monitoring support staff (the anesthetist may set case-specific bands that override; assistants report at whichever is tighter). DVM to confirm every value:
| Parameter | Draft default band |
|---|---|
| HR canine | <60 or >140 (size-adjusted by DVM) |
| HR feline | <120 or >200 |
| MAP | <60 mmHg (or Doppler systolic <90) — and any steady downtrend |
| SpO2 | <95% (any waveform quality — report includes waveform description) |
| EtCO2 | <25 or >55 mmHg; inspired CO2 >0 persistent; any waveform loss/shape change |
| Temp | <97.5°F or falling >1°F/30 min; >103°F |
| Also always | apnea >30 s; bag/chest discrepancy; MM/CRT change; depth-sign changes; any equipment fault |
