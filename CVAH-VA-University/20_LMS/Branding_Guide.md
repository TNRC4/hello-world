# CVAH Veterinary Assistant University — Branding Guide

Version 1.0 · 2026-08-17 · Tagline everywhere: **Learn it. Practice it. Prove it. Use it.**

**Character:** veterinary, modern, clinically credible, welcoming, serious about skill. Banned: cartoon animals in clinical contexts, paw-print confetti, badge-cartoon gamification, corporate-training stock blandness.

**Logo treatment:** wordmark "CVAH University" in the display face with a single-line caduceus-free veterinary mark: a minimal line-icon combining a stethoscope curve forming an open circle (suggesting both monitoring and completeness); monochrome-first design; clearspace = x-height of "U". Production spec for a designer; interim text-wordmark acceptable at launch.
**Typography:** headings — a humanist sans (e.g., Source Sans 3 / open license); body — same family; mono for IDs (skill/QB codes). No more than two weights per page.
**Color:** primary Deep Teal `#0F6B6B` (clinical, calm) · secondary Slate `#2F3B45` · accent Amber `#D9A21B` (used ONLY for safety-critical flags and ★ markers — the accent means "attend") · success Green `#2E7D4F` · alert Red `#B3392F` (report-now urgency tiers only) · neutrals warm gray ramp. Accessibility: all text pairs ≥ WCAG AA.
**Course thumbnails:** flat duotone (teal/slate) photographic crops of real hands-on work (gloved hands, instruments, monitors) with a one-word overlay (RESTRAINT · VENIPUNCTURE · RECOVERY). Consistent crop grid.
**Competency badges:** circular, engraved-line style, level ring (VA1 single ring, VA2 double, VA3 triple), specialty badges carry a single instrument icon (vaporizer dial, microscope, tooth, x-ray tube, star-of-life, kennel, mortar); every badge back-face/hover shows the internal-credential disclaimer.
**Certificates:** landscape, generous whitespace, wordmark top-left, credential name in display size, signatories + dates, disclaimer footer verbatim, version/verification ID (links to transcript record).
**Dashboards:** light UI on warm-gray, teal for progress states, amber/red reserved for flags (see color law above); passport states rendered as a 14-step horizontal tracker, current state solid.
