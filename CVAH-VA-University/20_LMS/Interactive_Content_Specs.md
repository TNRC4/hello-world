# Interactive Learning Asset Specifications (H5P build list)

Each spec: type · content · data source · pass logic. All original artwork per licensing register (26_).

INT-02 SBAR-V builder — Drag-the-Words ×3 scenarios; fragments → S/B/A/R/V slots; keyed per TS-COM-001.

INT-04 Vascular anatomy labeling — Image Hotspots/DragQuestion on 6 original vessel diagrams (dog/cat × cephalic/saphenous/jugular) + "where do you occlude?" hotspots.
INT-05 Tube-match & fill-order — Drag-and-drop: orders→tubes; sequencing: fill order; artifact photo gallery with cause-matching.
INT-06 Catheter troubleshooting — Branching Scenario per SIM-CORE-002 script (8 nodes, consequence branches, hard-fail loops).
INT-07 Body-language reader — 20 original/licensed photos, signal labeling, escalation-ladder ordering.
INT-08 Instrument ID — flashcards + tray hotspot images, ≥90% gate for W5-04.
INT-09 Heart/lung sounds & rate counting — Audio + Question Set; count-along with keyed rates; purr/pant confounders included.
INT-10 Emergency recognition set — 40 presentation stimuli (image/video), two-part items per Recognition Battery form.
INT-11 Smear quality card — image self-check gallery: 4 classic bad smears + causes; used at bench.
INT-A1/A2 Cardiac cycle & gas exchange diagrams — labeled-diagram interactives for ANE-M1.
INT-A3 Capnogram library — 12 waveform tracings (original vector art) with pattern-matching + five-question overlay per ANE-L1.
INT-D1 Triadan labeling — dental chart drag-label, 20 teeth.
INT-I1 Imaging fault gallery — 20 images, fault + one-fix pairing.
INT-N1 Pain-scale calibration — 10 short videos scored against keyed house-scale values; inter-rater gate for INP-M1.
INT-E1 Triage drill deck — 40 timed presentations, tier-sorting.

Production notes: build order follows Core week order (INT-01..09 first); each asset lists in the Asset Register with license `original-CVAH`; photo/video capture per Video System shot days (patients: staff-owned volunteers with signed releases, or licensed stock — never client patients without written consent per policy).
