# Video System — Production Plan

**Doctrine:** short technical videos (2–6 min) over lectures; every major skill gets a demo video or a complete storyboard (this plan); "correct + common-incorrect" pairing wherever error recognition is the point. All videos: phone-gimbal quality acceptable; overhead + side angles; on-screen step labels; captions mandatory (accessibility); transcript stored alongside; patients = staff-owned volunteers with releases or models; narration by CVT.

**Standard shot grammar:** cold open showing the finished correct outcome (5 s) → equipment layout flat-lay → procedure real-time with labels → the 2–3 classic errors performed on MODEL with red border frame → recap checklist card. Runtime target on label.
