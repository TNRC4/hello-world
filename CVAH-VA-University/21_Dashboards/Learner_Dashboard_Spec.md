# Learner Dashboard — Specification

**Top band:** name · VA level chip · Core progress ring (gates 1–9 as segments, not % of clicks) · active specialty chip. **Passport panel:** table of skills with the 14-state tracker (current state solid teal; states 11/13 amber with linked plan; 12/14 red-outline with revalidation booking link); filter by domain; every row shows supervision level + scope class explicitly. **Now panel:** modules due this week · floor-practice targets remaining (from repetition requirements vs logged counts, e.g., "cephalic: 3 of 5 coached draws logged") · assessments awaiting sign-off · booked practicals. **Case-log panel:** per loggable skill — attempts/success trend sparkline, patient-type spread checklist. **Achievements:** credential badges (earned solid, in-progress outlined), revalidation dates. Tone rules per branding: professional; progress is shown as evidence accumulating, not confetti; remediation items render identically to any other assignment (no stigma styling).
Implementation: Moodle dashboard blocks + Configurable Reports at launch; data from gradebook + competency framework + case-log databases.
