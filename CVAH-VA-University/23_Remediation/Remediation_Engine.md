# Remediation Engine

Version 1.0 · 2026-08-17

**Doctrine:** targeted, prescribed from a catalog, stigma-free, tracked for effectiveness. Never "retake the course." Trigger sources: failed knowledge check (after 2 attempts) · failed practical / CF event · unsafe-behavior flag · decay/revalidation lapse · trend in case logs (success rate falling) · manager/trainer referral.

## Pathway catalog
| Deficit pattern | Prescription | Completion signal |
|---|---|---|
| Venipuncture mechanics (miss pattern at steps 4–7) | W3-01 anatomy re-take + VID review + 10 model sticks + 3 coached draws with named focus | Coach sign-off → PA re-attempt |
| Venipuncture judgment (attempt-limit/stop-criteria) | SIM-CORE-003 repeat ×2 with different scripts + spec §15–16 oral walk-through | Scenario pass + Assessor conversation logged |
| Catheter threading | Model lab ≥5 + slow-mo video self-review vs VID-IVC + 2 coached | PA re-attempt |
| Medication math | INT-03 assigned sets (error-pattern-matched: decimals vs units vs concentration) until 3 consecutive clean sets | Re-screen ≥90% |
| Med verification behavior (choreography skips) | TS-MED-001 re-read + 5 observed preps with verifier scoring each check aloud | Zero-skip streak signed |
| Weak patient recognition | Recognition battery practice mode + assigned SIM trend cases + 1 week of "findings journal" (3 noticed-and-reported items/shift) | Battery re-take ≥85% |
| Documentation quality | Entry-makeover exercises + 10 real entries co-signed | Audit clean |
| Restraint safety | PA-RES re-training block with trainer + video review | PA re-attempt |
| Sterile-conscience lapses | W5-02 re-take + 10 sabotage-drill openings (catch rate 100%) | Drill log |
| Unsafe behavior (any CF class) | Formal: incident review with Assessor+Manager, root-cause conversation, prescribed pathway above + formal reassessment; DVM notified | Reassessment + 30-day clean follow-up |
| Knowledge failure (module) | SPECIFIC failed objectives re-assigned (item-map identifies lessons), not whole weeks | Targeted quiz ≥80% |

## Tracking
Every episode: trigger → prescription → completion → re-assessment outcome → 60-day durability check (did the deficit recur?). Effectiveness metric feeds 22_Analytics; pathways with poor pass-after rates get redesigned, not learners blamed. Learner-facing record shows current assignments only; full history in audit layer.
