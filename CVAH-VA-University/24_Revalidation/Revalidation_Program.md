# Continuing Competency & Revalidation Program

Version 1.0 · 2026-08-17

## Cadence table
| Item | Interval | Form |
|---|---|---|
| Safety refresher (OSHA/sharps/PPE/zoonoses) | 12 months | Module + 100% quiz |

| Infection control | 12 months | Module + isolation drill |

| Venipuncture/IVC/injections | 24 months OR decay rule (6 months no logged reps) | Case-log review; PA re-check if decayed |
| Anesthesia monitoring practical | 24 months | PA-ANES-MON-001 abbreviated |
| Specialty credentials | 24 months (Imaging 12 for safety unit) | Per-academy revalidation packet |

## Mechanics
System flags Revalidation Due (state 12) at T-60 days → dashboard + notification; lapse past due date → Competency Expired (state 14): capability matrix goes red, workload rows deactivate, manager alerted. Revalidation is proportionate: current, active practitioners with healthy case logs get streamlined re-checks; decayed skills get the fuller pathway.

## Emergency curriculum updates
Trigger classes: guideline changes (e.g., RECOVER revisions), equipment changes (registry-driven), regulation changes (scope matrix watch), hospital policy changes, incident-derived lessons. Path: Medical Reviewer approves change → affected modules/CRCs revised (MAJOR version) → push-notification module assigned to affected staff with acknowledgment tracking → manifest logs the campaign.
