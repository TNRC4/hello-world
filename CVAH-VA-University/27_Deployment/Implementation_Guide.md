# CVAH Implementation Guide

Version 1.0 · 2026-08-17 · Audience: practice manager + medical director. This is the "what do we actually do" document.

## Phase A — Localize (Weeks 1–3, ~15 staff-hours total)
1. Assign roles (Governance doc): Program Administrator, Medical Reviewer, 2+ Assessors, Supervising Techs.
2. Complete the Discovery Questionnaire (00_) and Equipment Survey (19_) — one afternoon.
3. Medical Reviewer reviews and approves: scope matrix rows + policy column (esp. SCOPE-004 IV-catheter and SCOPE-007/011/015 decisions), CRC-001/002/003/005 draft cards, critical-fail lists. Verify statute/rule text against vetboard.az.gov current PDFs; log in the Regulatory Research Log.
4. Fill `[CVAH-SPECIFIC INPUT REQUIRED]` items (grep the repo for the tag — each is a decision or a fact, none is authoring work).

## Phase B — Stand up the LMS (Weeks 2–4, parallel)
Per `20_LMS/Moodle_Deployment_Guide.md`: provision → import Core W0–W2 first (rolling import beats big-bang) → convert QB files to GIFT → wire conditional release → pilot with two current staff members through Week 0–1 → fix friction → import remaining weeks + Reference Library (approved CRCs only).

## Phase C — Train the trainers (Week 4)
Half-day session: Assessors practice the rubrics on each other (calibration: two assessors score the same performance, discuss gaps >2 points); trainers learn the daily integration rhythm; everyone drills the assessor mobile flow to the 60-second standard.

## Phase D — First cohort (Weeks 5–13)
Enroll 1–2 new hires (or challenge-testing current assistants — often the best pilot: they validate challenge-out AND get credentialed). **Daily rhythm (workplace integration):** before-shift/protected block 30–45 min = assigned lesson · during shift = training board flags learner-appropriate cases; trainer creates designated practice opportunities · competency moments = assessor observes when flagged ready · end of shift 10 min = log attempts + feedback · system assigns next. **Weekly:** trainer+learner 15-min passport review; manager glances at the exposure-diagnosis panel (is scheduling starving the learner of cases?).
Existing-staff track: challenge-testing sweep converts current assistants' real skills into passport states in ~2–4 weeks of opportunistic assessment — do this early; it populates the capability matrix and normalizes the assessment culture.

## Phase E — Operate (ongoing)
Monthly: analytics review (15 min in the manager meeting: transfer metrics + program health) · KB failed-search review → new cards. Quarterly: mock code (SIM-CORE-004) · LASA shelf audit (Pharmacy credential holder) · content release + license audit. Annually: scope re-verification · repetition-requirement calibration against attempts-to-competency data · full QA cycle (27_/QA_Report.md as the template).

## Budget summary (verify current prices)
LMS US$10–50/mo · model arms/limbs one-time ~US$200–600 (or clinic-built) · CPR manikin if not owned ~US$150–500 · print/laminate trivial · video production in-house (phone + $50 gimbal) · staff time is the real cost: ~0.5–1.0 FTE-hours/day of trainer attention per active learner in Weeks 0–4, tapering after — priced into the 6–8-week payoff by the transfer metrics.

## The Monday-morning test, answered
A new hire can start Week 0 the Monday after Phase C completes: pretest exists, lessons exist, floor targets exist, rubrics exist, logs print on one sheet. The only true blockers are the DVM approvals in Phase A — protect those 4–6 reviewer hours above all else.
