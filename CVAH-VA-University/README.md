# CVAH Veterinary Assistant University
**Learn it. Practice it. Prove it. Use it.**

A complete internal education, competency-management, and workforce-readiness system for Chino Valley Animal Hospital: one mandatory Core Academy (~6–8 weeks, competency-based), seven stackable specialty academies, a Technical Skills Library where every hands-on skill is a first-class object, a 14-state Digital Competency Passport, 294-item assessment banks, behavioral practical rubrics with a critical-fail system, simulations, controlled clinical references under veterinarian governance, an Arizona scope matrix, and a full Moodle deployment package.

**Start here:** `00_Project_Control/Executive_Overview.md` → `27_Deployment/Implementation_Guide.md`.
**Build state:** `00_Project_Control/BUILD_MANIFEST.json` + `CONTINUATION_STATE.md`.
**Governing docs:** `01_University_Governance/University_Charter.md` (mission, three questions of competence, conflict hierarchy).

⚠ All Controlled Reference Cards (`18_Controlled_References/`) are DRAFT pending reviewing-veterinarian approval; the scope matrix requires verification against current Arizona statute/rule text before first clinical use. Items tagged `[CVAH-SPECIFIC INPUT REQUIRED]` are the localization worklist.
